Privacy Policy — Manamum Gunamum

Last updated: 11 November 2026

About this app

"Manamum Gunamum" is a private, single-user automation tool. It is used only by the owner of the Manamum Gunamum YouTube channel to upload his own pre-recorded videos to his own channel through the YouTube Data API.

What data the app accesses

Through Google OAuth, with the account owner's explicit consent, the app accesses:

  • The owner's YouTube channel, only to upload videos and set their titles and descriptions (scopes: youtube.upload and youtube).

The app does not access Gmail, Google Drive, contacts, or any data belonging to any other person. No member of the public uses this app, and no third-party user data is collected, read, or stored.

How the data is used

The access is used for one purpose only: publishing the owner's own videos to his own YouTube channel on a daily schedule. Nothing else is done with the access.

Storage

The OAuth refresh token issued to this app is stored only on the operator's private computer, in a local file used by the upload tool. No data is stored on external servers by this app. No data is sold, rented, shared, or transferred to any third party. No advertising or analytics services are used.

Revoking access

The account owner can revoke this app's access at any time from Google Account → Security → Third-party access, which immediately stops the tool from uploading.

Data deletion

Because the app stores no user data beyond the locally kept OAuth token described above, deleting that local token file removes all stored access. For any question about this, contact the email below.
